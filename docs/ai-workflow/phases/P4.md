# P4: Retrieval: query decomposition, hybrid search, rerank, cited streaming answers
Mode: plan first. Implement only after I approve.

## Goal
`POST /ask` streams a grounded answer with `[n]` citations that map to document + page. It uses query decomposition, `FT.HYBRID` (text + vector, RRF fusion, tenant pre-filter), a rerank step and an abstain rule.

## Read these files
- `CLAUDE.md`
- `docs/specs.md`, section 5 ("Retrieval and answer pipeline", "Redis index"), section 6 (`/ask`) and section 7 (flow 3)

## Constraints
- **Retriever interface** with 3 strategies, selectable by config so P5 can compare them: `vector_only`, `hybrid`, `hybrid_rerank`.
- **Decomposition:** one cheap LLM call returns JSON `{sub_queries: [...]}` (at most 3). Skip it for short single-intent questions (a heuristic: fewer than 12 words and no "and/compare/vs").
- **Hybrid:** use `FT.HYBRID` with RRF and `@tenant:{id}` as a pre-filter. Take the top 20 per sub-query, then merge and de-duplicate by chunk id. If the redis-py version has no helper, call it through `execute_command` and parse the reply in one small, tested function.
- **Rerank:** an LLM listwise rerank of up to 20 candidates down to the top 6, returning ids only. Keep the prompt short and output JSON only.
- **Answer prompt:** numbered blocks `[n] (doc title, p.X)`, plus these rules:
  - cite every claim
  - answer only from the context
  - otherwise reply exactly "Not found in the documents."
- **Streaming:** SSE via Flask `stream_with_context`, sending `token` events and then one `citations` event `{n, document_id, title, page}`.
- **Cost:** log the token counts of each LLM call per request (no text) to support the token-efficiency story.

## Deliverables
- The retriever strategies, decomposer, reranker, answerer and the `/ask` SSE route
- Chat UI: question box, streaming answer, clickable `[n]` chips that open the document page (via a presigned GET)
- Tests:
  - the FT.HYBRID reply parser
  - tenant isolation: tenant B's question never returns tenant A's chunks
  - the abstain path
  - the citation numbering matches the blocks

## Done when
- On the sample corpus, 5 hand-picked questions get correct, cited answers. An off-topic question returns the abstain message.
- The isolation test passes.
- The per-request token log shows decomposition, rerank and answer tokens separately.

## Out of scope
The eval harness (P5), multilingual queries and versioned circulars (Phase B).
