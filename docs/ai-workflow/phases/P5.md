# P5: Eval harness, load test, deploy, publish numbers
Mode: plan first. Implement only after I approve.

## Goal
Measure retrieval and answer quality on a fixed golden set, comparing the 4 configs. Measure ingestion throughput, deploy to EC2, and publish the results that become the resume numbers.

## Read these files
- `CLAUDE.md`
- `docs/specs.md`, sections 9 (evaluation harness) and 10 (test matrix)
- `apps/api/retrieval/*`

## Constraints
- **Corpus:** a public document set, 30–60 PDFs. For example, a set of RBI or UGC circulars, or a university academic rulebook. It doubles as the Phase B base.
- **Golden set `eval/golden.jsonl`:** 30–50 rows of `{id, question, expected: [{document, page}], reference_answer, answerable}`. Include about 5 unanswerable questions. **Write or review the questions yourself.** Claude may draft them, but you must check each one against the PDF.
- **Metrics:**
  - hit@5 and MRR, from the retrieved chunk pages vs the expected pages
  - faithfulness: an LLM judge returns, for each answer sentence, whether it is supported by its cited block; report the share supported
  - abstention accuracy
  - average tokens and latency per question
- **Configs to compare:** `vector_only`, `hybrid`, `hybrid_rerank`, `hybrid_rerank_decomp`. Store each run in `eval_runs` and produce a markdown table.
- **Ingestion load:** upload 200 docs in one batch. Measure documents/min, p95 time per stage and the peak queue depth.
- **Deploy:** GitHub Actions (CI with pytest; deploy over SSH to EC2 with compose + Flyway), a Caddy block for `pagecite.<yourdomain>`, Route 53, and an S3 bucket with a tenant-prefix IAM policy.

## Deliverables
- `eval/run.py`, the configs, `docs/results.md` (eval table, ingestion numbers, environment, commit SHA), the CI/CD workflows
- A 60–90 s demo: upload a batch, show live progress, ask a question and get cited answers, ask an unanswerable one and get "Not found", and show the eval table

## Done when
- The eval table exists for all 4 configs, and the best config is identified with real numbers.
- The public URL works and CI is green.
- The resume bullets are updated with measured hit@5, faithfulness and docs/min.

## Out of scope
Supersession graph, as-of-date queries, Hindi (all Phase B).

## Finish
Fill in the log totals.
